1. Ingestion & Preprocessing 01_loading & 03_prep

Zero Data-Leakage Protocol

Standard flaw in student ML projects: applying imputation or scaling on the full dataset before splitting. Our pipeline enforces strict segregation:

  • Stratified Train/Test Split (80/20): Preserves original target ratio (26.54% churn) across folds.
  • Whitespace & Type Coercion: Coerces 11 empty space string values in TotalCharges to NaN.
  • Train-Fitted Median Imputation: SimpleImputer(strategy='median') fits on X_train ONLY, preventing test set leakage.
  • One-Hot Encoding with Dummy Trap Prevention: Encodes categorical variables using drop_first=True ($k-1$ dummies).
  • Z-Score Standard Scaling: StandardScaler() scales features based exclusively on training distribution ($\mu_{\text{train}}, \sigma_{\text{train}}$).
Reference: src/preprocessing.py
2. Class Imbalance Handling 04_churn_models

Imbalanced Learning & Resampling

The dataset contains 73.4% Retained vs. 26.6% Churn (2.76:1 ratio). Naive accuracy is misleading (73% by predicting zero):

  • SMOTE (Synthetic Minority Over-sampling): Synthesizes minority samples along $k$-nearest neighbor vectors in feature space.
  • Algorithm Class Weighting: Leverages scale_pos_weight = (N_{neg} / N_{pos}) \approx 2.76 in XGBoost to penalize false negatives.
  • Stratified $K$-Fold Cross Validation: 5-fold stratification ensures balanced validation splits for hyperparameter tuning.
  • Evaluation Metrics Focus: Prioritizes PR-AUC, ROC-AUC (0.854), and Recall (0.81) over pure accuracy.
Recall Target: > 80% Churn Capture

4. Explainable AI (XAI) 06_explainability

SHAP (Shapley Additive exPlanations)

Moving beyond "black box" machine learning to explain both global feature importance and local single-customer decisions using cooperative game theory:

\phi_i = \sum_{S \subseteq F \setminus \{i\}} \frac{|S|!(|F|-|S|-1)!}{|F|!} [f(S \cup \{i\}) - f(S)]
  • Local Waterfall Plots: Decomposes log-odds prediction into additive contributions for each individual subscriber.
  • Global Feature Importance: Uncovers that Contract Type, Tenure, and Tech Support dominate churn probability across the whole population.
Reference: src/explainability.py
5. CLV & Discounted Cash Flow 07_clv_simple

Customer Lifetime Value (CLV) Math

Converts pure ML classification probabilities into actionable balance-sheet financial assets via Discounted Cash Flow (DCF):

CLV = \sum_{m=1}^{T_{\text{rem}}} \frac{\text{MonthlyCharges} \times \text{Margin}}{(1 + r_{\text{month}})^m}
  • Gross Margin ($\gamma$): Fixed at 40% based on telecom telecom infrastructure operating expenses.
  • Discount Rate ($r$): Annual cost of capital $10\%$ ($\approx 1\%$ monthly compounding).
  • Expected Remaining Horizon: $T_{\text{rem}} = \frac{1 - P_{\text{churn}}}{P_{\text{churn}}} \times \kappa$.
Reference: src/clv.py
6. Survival Analysis 08_clv_survival

Kaplan-Meier & Cox Proportional Hazards

Standard classification treats tenure as static. Survival analysis accounts for right-censoring (customers who haven't churned yet):

h(t | X) = h_0(t) \exp\left( \sum_{j=1}^p \beta_j X_j \right), \quad S(t) = \prod_{t_i \le t} \left( 1 - \frac{d_i}{n_i} \right)
  • Hazard Ratio ($e^{\beta}$): Quantifies multiplier on instantaneous churn risk for Fiber Optic vs. DSL.
  • Survival Curve Integration: Integrates area under the curve to yield true expected lifetime in months.
Tool: lifelines library
7. Cost-Sensitive Tuning 05_tuning

Cost-Matrix Optimal Thresholds

Standard 0.5 decision threshold is economically sub-optimal because asymmetric error costs exist in real business:

Cost False Negative $500 (Lost Customer)
Cost False Positive $50 (Wasted Voucher)

By sweeping decision thresholds from 0.05 to 0.95, the optimal profit-maximizing threshold was found at $P_{\text{thresh}} = 0.32$ instead of default 0.50.

Optimal Cutoff: 0.32
